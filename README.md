# My Diary Board

개인 Notion DB를 모바일 친화적인 카드형 보드로 보여주는 프로젝트입니다.

## 현재 단계

- 기본 페이지 구성
- Pinterest 느낌의 카드 레이아웃
- 모바일 대응 스타일
- 추후 Notion DB, GitHub, Cloudflare Pages 연결 예정

## 앞으로 붙일 수 있는 기록 종류

- 일기와 감정 기록
- 운동, 수면, 루틴
- 프로젝트 진행 상황
- 문장, 링크, 이미지 아카이브
- 소비 기록
- 아이디어 인박스

## 로컬 확인

브라우저에서 아래 주소로 확인합니다.

```txt
http://127.0.0.1:8844/
```
